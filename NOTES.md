# Заметки для продолжения (передать любому Клоду)

Мод **trypc** (Fabric, Minecraft 1.21.11, Yarn 1.21.11+build.4). Автор: Семён Гридин. Объясняй ему просто и коротко, по-пингвиньи 🐧❄️

## Что уже есть
- `src/main/java/com/trypc/TrypcMod.java` — всё в одном файле.
- Смерть игрока (`ServerLivingEntityEvents.ALLOW_DEATH`): вещи забираются из инвентаря, на месте смерти создаётся манекен (`minecraft:mannequin`) командой `summon` со скином игрока, позой по причине смерти и подписью.
- Падение: тело кружится и замирает (`tickSpins`).
- Обычный режим: при возрождении (`AFTER_RESPAWN`) труп исчезает, вещи выпадают.
- Хардкор: труп остаётся, вещи в нём (хранятся в командном хранилище `trypc:corpses`), забрать — ПКМ по трупу.

## Как собирать
Файлы загружаются в репозиторий, GitHub Actions (`.github/workflows/build.yml`) собирает jar, он появляется на странице Releases. Локально собрать нельзя (нет доступа к Minecraft-репозиториям). Ошибки компиляции читать так: `gh run view <id> --log-failed`.

## Что ещё не проверено в игре
- как выглядят позы `sleeping`, `swimming`, `crouching` у манекена, куда он повёрнут;
- правильно ли кружится тело при падении;
- не пропадают ли вещи при перезапуске сервера.
Семён тестирует в хардкор-мире и пришлёт скриншоты. Подправь позы и вращение по ним.

## Идеи
- команда `/trypc test` для проверки поз без смерти;
- на 1.21.11 API часто отличается от старых версий: геттеры NBT возвращают Optional (есть варианты с запасным значением), у `ServerPlayerEntity` нет `getServer()` (берём через `getEntityWorld()`), команды выполняются через `getDispatcher().execute(...)`.
