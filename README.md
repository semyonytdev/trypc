# trypc (Трупы) — Fabric, Minecraft 1.21.11

Серверный мод (работает и в одиночной игре):
- при смерти вещи **не разлетаются**, а появляется труп (манекен со скином игрока);
- поза зависит от причины смерти (упал, утонул, сгорел, взорван, убит);
- если упал, тело кружится в случайную сторону и замирает;
- обычный режим: при возрождении труп исчезает, вещи выпадают из него;
- хардкор: труп остаётся, вещи хранятся в нём; забрать их можно, нажав ПКМ по трупу.
